## 另一个收获：它今天第二条规矩

它在更早一条消息里说已经加进手册第 8 条：

> **「验法要能报错，不能只能点头」**

背景是那个三角（入口 / 主题 / 验法）：

```
入口能指错、主题能搜错，
只有验法能在前两个都错的时候把问题照出来。
```

所以验法必须是「tree 出来看文件名变了没有」这种**会明确报错**的，
而不是「搜索一下看命中没有」那种**永远能返回点什么**的。

**这条对记忆系统验收同样适用**：一周后验收不能只「搜一下有没有新内容」，
必须直读文件比行数字节数（`wc -l` / `wc -c`），那才是会报错的验法。
